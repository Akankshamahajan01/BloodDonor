# 🩸 BloodDonor – Real-Time Blood Donation Platform

A lifesaving, user-friendly web application designed to **connect blood donors with recipients in real time**, making emergency blood requests faster, easier, and more accessible.

---

## 🚀 Key Features

### 1. 🩸 Blood Donor Finder

* **Blood Group Search:** Find suitable donors based on required blood group.
* **Location-Based Search:** Search for donors according to their location.
* **Donor Availability:** Check available donors for emergency requirements.
* **Quick Donor Matching:** Helps recipients find compatible donors quickly.

### 2. 👤 User Authentication & Profiles

* **Sign In & Sign Up:** User registration and login functionality.
* **User Authentication:** Secure access to user-specific features.
* **Donor Profile:** Store donor details including blood group, location, and availability.
* **Profile Management:** Users can view and manage their information.

### 3. 🚨 Emergency Blood Requests

* **Create Blood Request:** Users can submit requests for required blood.
* **Blood Group Selection:** Specify the required blood group.
* **Location Details:** Add the location where blood is needed.
* **Request Management:** Easily manage and track blood requests.

### 4. 📊 Dashboard & Donor Management

* **User Dashboard:** Centralized view of donor and recipient activities.
* **Donor Information:** Display relevant donor details.
* **Request Status:** Manage active blood requests.
* **Easy Navigation:** Simple interface for accessing major platform features.

### 5. 👥 About Us & Team

* **About Us Page:** Explains the mission and purpose of BloodDonor.
* **Meet the Team:** Dedicated section introducing the development team.
* **View Profile:** Individual team member profile pages.
* **Interactive UI:** Smooth animations and responsive design.

### 6. ❓ FAQ & User Support

* **Frequently Asked Questions:** Answers common blood donation queries.
* **Interactive FAQ:** Expandable questions and answers.
* **Easy-to-Understand Information:** Helps users understand the donation process.

### 7. 🌙 Modern & Responsive UI

* **Dark / Light Mode:** Switch between different appearance modes.
* **Responsive Design:** Works across desktop, tablet, and mobile screens.
* **Smooth Animations:** Interactive transitions and animations.
* **Clean Interface:** Simple and user-friendly navigation.

* **Backend:** Node.js, Express.js
* **Database:** SQLite
* **Authentication:** Login & Registration System
* **APIs:** REST API integration
* **Development Tools:** Git, GitHub, VS Code

## 🎯 Project Objective

BloodDonor aims to simplify the process of finding and connecting with blood donors during emergencies by providing a centralized digital platform for **donors, recipients, and blood requests**.
